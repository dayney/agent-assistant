# 规则管理实施计划

> 在一次规则区域提交中执行此计划。不要开始技能管理。

1. 为规范规则加载/保存、适配器派生的目标添加失败的 Go 测试，
   漂移阻止、本机导入、备份覆盖、本地项目注册表以及
   确定性/人工智能分析边界。
2.为规则编辑器模型、预览状态、冲突添加失败的前端测试
   分辨率和手动项目导入。
3. 将生产适配器注册表提取到共享内部包中，以便
   CLI 和桌面 Core 使用相同的完整适配器集。
4. 使用 `source`、`render`、`drift` 实现 `internal/desktopcore/rules.go`，
   `state`，以及全局锁。保持规范源和目标状态为
   唯一的写入权限。
5. 使用可注入命令运行程序实现可选的本地 Codex 分析器
   和严格的 JSON 模式。测试使用假跑步者；没有测试调用模型。
6. 扩展Rule和Tauri IPC命令的sidecar请求协议和Tauri IPC命令
   项目导入业务。
7.用编辑器、目标预览、blocked-Diff替换Rule原型
   对话和明确的解决措施。添加手动项目导入和
   提案审核流程。
8. 更新自述文件、架构、组件、用户指南、网站参考和
   同一提交中的变更日志。
9. 运行重点 Go 测试、前端测试/构建、Rust 格式/检查、完整相关
   Go 测试、Tauri 发布版本和真实的 macOS UI 验证。
10. 作为一项常规规则区域提交进行提交，然后在技能工作之前停止。
